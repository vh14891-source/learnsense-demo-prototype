# LearnSense AI

Machine learning based system that identifies a student's learning preference (VARK) and engagement depth (Deep / Surface).

## Tech Stack
- Python, Flask
- scikit-learn
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Install packages: `pip install -r requirements.txt`
3. Train the models: `python train_model.py`
4. Start the server: `python server.py`
5. Open http://127.0.0.1:5000

## Features
- Form to collect student study habits
- Predicts learning preference and engagement depth
- Model evaluation tables and charts
