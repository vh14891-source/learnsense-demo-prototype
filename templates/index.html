About the Project

LearnSense AI analyzes student learning and study behaviour using Machine Learning. Pipeline: Student Data → Preprocessing → Feature Engineering → ML Model (Decision Tree, Random Forest, KNN, Logistic Regression) → Student Learning Profile.

Front end: HTML, CSS, JavaScript   Back end: Python (Flask, scikit-learn)

Results show indicative patterns, not a diagnosis of any student. The prototype uses a simulated dataset because real student logs are hard to collect.
